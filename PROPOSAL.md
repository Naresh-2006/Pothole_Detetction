Project Proposal
Title
Pothole Detection using YOLOv11
Problem Statement
Road damage such as potholes and cracks reduces safety and increases maintenance costs. Manual inspection is slow and expensive. This project automates road damage detection using deep learning.
Objectives
• Detect potholes
• Detect road cracks
• Identify normal road surfaces
• Build a Streamlit dashboard for image upload and prediction.
Proposed Solution
Train a YOLOv11 object detection model on a Roboflow dataset and deploy it through a Streamlit application.
Methodology
1. Dataset collection from Roboflow
2. Data preprocessing
3. YOLOv11 training in Google Colab
4. Model evaluation
5. Streamlit deployment
Software Requirements
Python, Google Colab, VS Code, Ultralytics YOLOv11, Streamlit, OpenCV, PyTorch.
Hardware Requirements
Laptop/PC, Internet connection, Google Colab Tesla T4 GPU.
Expected Outcome
A web dashboard capable of detecting potholes, cracks and normal road regions from uploaded images.
Future Scope
Real-time video detection, GPS integration, mobile deployment, larger datasets.
